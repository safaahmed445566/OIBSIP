# Basic Functional Calculator

## About the Project
A basic calculator developed for Task 1 of my Oasis Infobyte Web Development Internship.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Performs basic arithmetic operations: addition, subtraction, multiplication, and division.
- Displays the current mathematical expression and calculation result.
- Supports decimal numbers and negative numbers.
- Follows operator precedence when evaluating expressions.
- Allows users to clear the entire expression.
- Includes a backspace button to remove the last entered character.
- Provides a sign-toggle button to change a number's sign.
- Handles division-by-zero errors with an error message.
- Uses an interactive button-based interface.
- Calculates expressions using custom JavaScript logic without using `eval()`.

## How to Run
Open index.html in a web browser.
