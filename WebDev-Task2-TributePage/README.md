# Jessica McCabe Tribute Page

## About the Project
A tribute page dedicated to Jessica McCabe, creator of How to ADHD, who helps people understand ADHD.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Tribute page dedicated to Jessica McCabe, creator of *How to ADHD*.
- Introduction highlighting her work and contributions to ADHD awareness.
- Biography and career information presented in organized sections.
- Jessica McCabe's image with a styled page layout.
- Interactive elements powered by JavaScript.
- User-friendly design with clear typography and visual styling.
- Responsive layout for different screen sizes.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Open `index.html` in a web browser.
